# minichain.github.io

Personal website of Minichain, served by GitHub Pages at minichain.es. Plain HTML/CSS/JS, no build step.

## Structure

- `index.html`: home page.
- `404.html`: page not found. It also redirects the old `<name>.html` URLs to the new `<name>/` folders.
- `projects/`: page listing all the projects.
- `<name>_project/`: one folder per project, with its page in `index.html`.
- `shared/`: styles, libraries and resources used by several pages.
- `index/`: scripts, styles and resources of the home page.

Each page folder usually contains `src/` (scripts), `styles/` and `res/` (images, audio...).
